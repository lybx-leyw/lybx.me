轴平行矩阵的PAC可学习性证明与实践

1. 问题定义 [返回目录]

考虑轴平行矩阵（Axis-Aligned Rectangle）问题。目标概念c是某个特定的轴平行矩阵，对于该矩阵中的点x有c(x)=1，对于其他点有c(x)=-1。

假设PAC可学习，那么对于任意精度参数ε和置信参数δ，存在一个多项式时间算法，能够以至少1-δ的概率得到假设h，使得对于所有x，|c(x)-h(x)|<ε，即 P(E(h) ≤ ε) ≥ 1-δ。

2. 理论基础 [返回目录]

PAC（Probably Approximately Correct）学习是计算学习理论中的核心概念。它关注两个关键参数：

  • 精度参数 ε：允许的学习误差
  • 置信参数 δ：学习算法失败的最大概率

本研究中，我们设定 δ=0.5，ε=0.1，即希望以至少50%的概率得到准确率超过90%的假设。

3. 算法Ω分析 [返回目录]

采用简单算法Ω：找到矩阵区域Rs正好能圈住经验数据集中所有标签为1的点。

记目标矩阵内的区域为R，我们分两种情况讨论：

情况1：P(R) ≤ ε

如果目标矩阵本身的概率质量足够小，则显而 P(E(h) ≤ ε) ≥ 1。

情况2：P(R) > ε

则存在四个以目标矩阵的边为边界的矩阵区域R₁, R₂, R₃, R₄，使得P(R₁)=P(R₂)=P(R₃)=P(R₄)=ε/4。

P(E(h) > ε) ≤ P(∪ᵢ(Rₛ∩Rᵢ=∅)) ≤ Σ(P(Rᵢ∩Rₛ=∅)) = 4(1-ε/4)ᵐ ≤ 4exp(-mε/4)

从而 P(E(h) ≤ ε) ≥ 1-4exp(-mε/4) ≥ 1-δ。

4. 样本复杂度推导 [返回目录]

对于任意ε和δ，只要 m ≥ log(4/δ) × 4/ε，则该算法能够以至少1-δ的概率得到假设h，使得 P(E(h) ≤ ε) ≥ 1-δ。

算法的运行时间复杂度和样本复杂度为 O(log(1/δ) × 1/ε)。

结论：该问题是PAC可学习的，且具有多项式级的样本复杂度。

5. 数值计算与实验验证 [返回目录]

取 δ=0.5，ε=0.1，则可以得到准确率为90%的假设h的概率大于50.0%。

至少要选取的样本数：m = 40×log(8) = 120×log(2) ≈ 83.17。

如果不进行保守估计，则最终m只需要满足：

m ≥ log(δ/4) / log(1-ε/4) = log(8) / (log(40)-log(39)) = 82.14

结论：至多需要选取83个样本，就能得到准确率为90%的假设h的概率大于50.0%。

6. 优化估计与实验验证 [返回目录]

事实上，对于δ=0.5，可以采用更简单的估计方法。

记整个地图长宽约为1，其中目标矩阵长宽均为0.5。对于该轴平行矩阵问题，使得Ω算法满足 P(E(h) ≤ ε) ≥ 1-δ。

即只需要目标矩阵内的样本围成的最大面积 > 0.15。

对于位于目标矩阵内均布的样本，mₖ个采样所得矩阵的中位数的期望面积为：

E(S) = 0.25 × (1 - 2/(mₖ+1))²

要使该期望面积大于0.15，则：

0.25 × (1 - 2/(mₖ+1))² > 0.15 ⇒ mₖ > 7.87 ⇒ m > 31.48

7. VC维与Rademacher复杂度 [返回目录]

在深入分析泛化误差界之前，我们需要理解两个重要的学习理论概念：VC维和Rademacher复杂度。

VC维分析

VC维（Vapnik-Chervonenkis Dimension）是衡量假设空间复杂性的重要指标。对于轴平行矩阵问题：

  • 3个样本：对于任意3个样本的所有可能标签，一定存在一个轴平行矩阵能够正确分类
  • 4个样本：当样本的标签交错分布时，将不存在一个轴平行矩阵能够正确分类

因此，算法Ω对应的假设空间H的VC维为3。

Rademacher复杂度分析

Rademacher复杂度衡量假设空间与随机噪声的相关性。从服从均布的噪声空间中采样噪声δ，考虑：

Eδ[sup 1/m Σᵢ δᵢh(xᵢ)]

假设δ严格均布，则上式等价于 sup 1/m Σᵢ δᵢh(xᵢ)。

对于轴平行矩阵算法，圈住的正样本数与负样本数最多相差1：

  • 圈住正样本点 - 负样本点数为1时：1/m Σᵢ δᵢh(xᵢ) = 1/m
  • 否则：1/m Σᵢ δᵢh(xᵢ) = 0

因此，算法Ω对应的假设空间的Rademacher复杂度为 1/m。

8. 泛化误差界实验验证 [返回目录]

基于上述理论分析，我们可以建立两种泛化误差界，并通过实验验证其准确性。

Rademacher复杂度泛化界

根据Rademacher复杂度的泛化界：

P(E(h) - Ê(h) <= 2Rₘ(H) + sqrt(log(1/δ)/(2m))) >= 1-δ

对于 δ=0.99，上式等价于：

P(E(h) - Ê(h) <= 2/m + sqrt(log(100)/2m)) >= 0.99

VC维泛化界

根据VC维的泛化界：

P(E(h) - Ê(h) <= sqrt((8*VCdim*(log(2em/VCdim))+8*log(4/δ))/m) >= 1-δ

其中VCdim为假设空间的VC维。对于 δ=0.99，上式等价于：

P(E(h) - Ê(h) <= sqrt((8*3*log(2em/3)+8*log(4.04))/m) >= 0.99

实验验证

本实验验证Rademacher复杂度对泛化上界的估计以及VC维的估计是否准确。计算真实误差 E(h) 与经验误差 Ê(h) 的差值，判断是否满足上界要求。

实验结果

  • 两种泛化界都验证了轴平行矩阵问题的PAC可学习性

PAC可学习性验证（PAC_1.py）

第一个实验验证了轴平行矩阵问题的PAC可学习性，包括样本复杂度推导和优化估计： 

"""
轴平行矩阵经典PAC可分算法的PAC可学习性证明与实践
============================================

理论基础
--------
考虑轴平行矩阵问题：
- 目标概念c是某个特定的轴平行矩阵
- 对于该矩阵中的点x有c(x)=1，对于其他点有c(x)=-1
- 假设PAC可学习：对于任意精度参数ε和置信参数δ，存在多项式时间算法
  能够以至少1-δ的概率得到假设h，使得对于所有x，|c(x)-h(x)|<ε
  即 P(E(h) <= ε) >= 1-δ

算法Ω分析
---------
算法Ω能找到矩阵区域Rs正好能圈住经验数据集中所有标签为1的点。

记目标矩阵内的区域为R：

1. 若P(R) <= ε，则显而 P(E(h) <= ε) >= 1

2. 若P(R) > ε，则存在四个以目标矩阵的边为边界的矩阵区域R1,R2,R3,R4
   使得P(R1)=P(R2)=P(R3)=P(R4)=ε/4

   则显而 P(E(h)>ε) <= P(∪i(Rs∩Ri=∅)) <= Σ(P(Ri∩Rs=∅))
    = 4(1-ε/4)^m <= 4exp(-mε/4)

   从而 P(E(h) <= ε) >= 1-4exp(-mε/4) >= 1-δ

样本复杂度
---------
对于任意ε和δ，只要 m >= log(4/δ) * 4/ε，则该算法能够以至少1-δ的概率
得到假设h，使得 P(E(h) <= ε) >= 1-δ

算法的运行时间复杂度和样本复杂度为 O(log(1/δ) * 1/ε)

数值计算
--------
取 δ=0.5，ε=0.1，则可以得到准确率为90%的假设h的概率大于50.0%

至少要选取的样本数：m = 40*log(8) = 120*log(2) ≈ 83.17

如果不进行保守估计 4(1-ε/4)^m <= 4exp(-mε/4)：
    m >= log(δ/4) / log(1-ε/4)
    = log(8) / (log(40) - log(39))
    = 82.14

结论：至多需要选取83个样本，就能得到准确率为90%的假设h的概率大于50.0%

优化估计（PS）
-----------
事实上，对于δ=0.5，可以采用更简单的估计：

记整个地图长宽约为1，其中目标矩阵长宽均为0.5
对于该轴平行矩阵问题，使得Ω算法满足 P(E(h) <= ε) >= 1-δ

i.e. 只需要目标矩阵内的样本围成的最大面积 > 0.15

对于位于目标矩阵内均布的样本，mk个采样所得矩阵的中位数的期望面积为：
    E(S) = 0.25 * (1 - 2/(mk+1))^2

要使该期望面积大于0.15，则：
    0.25 * (1 - 2/(mk+1))^2 > 0.15
    => mk > 7.87
    => m > 31.48

因此，实际只需要32个样本即可达到要求。
"""


# 我们不妨就上述理论进行模拟实验
def Experiment(
        sample_size,
        map_size=1.0, target_start=0.25, target_end=0.75,
        delta=0.5, epsilon=0.1,
        tests_num=1000
    ):
    import numpy as np

    # ========== 常量定义 ==========
    # 地图和目标矩阵的边界
    MAP_SIZE = map_size                     # 地图区域
    TARGET_START = target_start             # 目标矩阵左边界
    TARGET_END = target_end                 # 目标矩阵右边界

    # PAC学习参数
    CONFIDENCE_DELTA = delta                # 置信参数δ
    ACCURACY_EPSILON = epsilon              # 精度参数ε

    # 实验参数
    TEST_COUNT = tests_num                  # 实验重复次数
    SAMPLE_SIZE = sample_size               # 每次实验的样本数量

    # 算法初始值
    BOUNDARY_INIT = -1.0                    # 边界初始值，随意赋值即可
    TARGET_AREA = (TARGET_END - TARGET_START)**2  # 目标矩阵面积

    # ========== 主程序 ==========
    success_count = 0                       # 成功次数计数器
    total_in_target = 0                     # 落入目标矩阵的总点数

    for _ in range(TEST_COUNT):
        # 生成随机样本
        x = np.random.rand(SAMPLE_SIZE)
        y = np.random.rand(SAMPLE_SIZE)

        # 初始化边界（算法Ω的输出矩阵边界）
        left = BOUNDARY_INIT
        right = BOUNDARY_INIT
        up = BOUNDARY_INIT
        down = BOUNDARY_INIT
        first = True

        # 算法Ω：找到能圈住所有标签为1的点的最小矩形
        for i in range(SAMPLE_SIZE):
            # 判断样本点是否在目标矩阵内
            in_target = (TARGET_START <= x[i] <= TARGET_END and
                        TARGET_START <= y[i] <= TARGET_END)

            if in_target:
                total_in_target += 1

                if first:
                    # 第一个正样本点：初始化边界
                    left = right = x[i]
                    down = up = y[i]
                    first = False
                else:
                    # 更新边界以包含当前点
                    if x[i] < left:
                        left = x[i]
                    if x[i] > right:
                        right = x[i]
                    if y[i] < down:
                        down = y[i]
                    if y[i] > up:
                        up = y[i]

        # 计算错误率：目标面积 - 学习到的矩形面积
        learned_area = (right - left) * (up - down)
        error = TARGET_AREA - learned_area

        # 判断是否满足精度要求
        if error < ACCURACY_EPSILON:
            success_count += 1

    # ========== 输出结果 ==========
    success_rate = success_count / TEST_COUNT

    return success_rate

泛化误差界验证（PAC_2.py）

第二个实验验证了VC维和Rademacher复杂度的泛化误差界： 

"""
轴平行矩阵泛化误差界实验验证
==============================

理论基础
--------
同样基于轴平行矩阵问题：
- 目标概念c是某个特定的轴平行矩阵
- 对于该矩阵中的点x有c(x)=1，对于其他点有c(x)=-1

算法Ω的假设空间H是空间中所有轴平行矩阵的集合。

VC维分析
---------
对于任意3个样本的所有可能标签，一定存在一个轴平行矩阵能够正确分类。
对于任意4个样本，当他们的标签交错分布时，将不存在一个轴平行矩阵能够正确分类。
因此，算法Ω对应的假设空间H的VC维为3。

Rademacher复杂度分析
---------------------
从服从均布的噪声空间中采样噪声δ，考虑 Eδ(sup 1/mΣiδih(xi))。

假设δ严格均布，则上式等价于 sup 1/mΣiδih(xi)。

对于轴平行矩阵算法，圈住的正样本数与负样本数最多相差1：
- 圈住正样本点 - 负样本点数为1时：1/mΣiδih(xi) = 1/m
- 否则：1/mΣiδih(xi) = 0

因此，算法Ω对应的假设空间的Rademacher复杂度为 1/m。

泛化误差界
----------
根据Rademacher复杂度的泛化界：
    P(E(h) - Ê(h) <= 2Rm(H) + sqrt(log(1/δ)/2m)) >= 1-δ
对于 δ=0.99，上式等价于：
    P(E(h) - Ê(h) <= 2/m + sqrt(log(100)/2m)) >= 0.99

根据VC维的泛化界：
    P(E(h) - Ê(h) <= sqrt((8*VCdim*(log(2em/VCdim))+8*log(4/δ))/m) >= 1-δ
其中VCdim为假设空间的VC维。
对于 δ=0.99，上式等价于：
    P(E(h) - Ê(h) <= sqrt((8*3*log(2em/3)+8*log(4.04))/m) >= 0.99

实验验证
--------
本实验验证Rademacher复杂度对泛化上界的估计以及VC维的估计是否准确。
计算真实误差 E(h) 与经验误差 Ê(h) 的差值，判断是否满足上界要求。
注意：本实验使用 δ=0.99（置信度99%）进行验证。
"""


# 我们不妨就上述理论进行模拟实验
def Experiment(
        sample_size,
        map_size=1.0, target_start=0.25, target_end=0.75,
        delta=0.5,
        tests_num=1000
    ):
    import numpy as np
    import math

    # ========== 常量定义 ==========
    # 地图和目标矩阵的边界
    MAP_SIZE = map_size                     # 地图区域
    TARGET_START = target_start             # 目标矩阵左边界
    TARGET_END = target_end                 # 目标矩阵右边界

    # PAC学习参数
    CONFIDENCE_DELTA = delta                # 置信参数δ

    # 实验参数
    TEST_COUNT = tests_num                  # 实验重复次数
    SAMPLE_SIZE = sample_size               # 每次实验的样本数量

    # 算法初始值
    BOUNDARY_INIT = -1.0                    # 边界初始值，随意赋值即可
    TARGET_AREA = (TARGET_END - TARGET_START)**2  # 目标矩阵面积

    # ========== 主程序 ==========
    success_count_1 = 0                     # 成功次数计数器（Rademacher复杂度界）
    success_count_2 = 0                     # 成功次数计数器（VC维界）
    total_in_target = 0                     # 落入目标矩阵的总点数

    for _ in range(TEST_COUNT):
        # 生成随机样本
        x = np.random.rand(SAMPLE_SIZE) * MAP_SIZE
        y = np.random.rand(SAMPLE_SIZE) * MAP_SIZE

        # 初始化边界（算法Ω的输出矩阵边界）
        left = BOUNDARY_INIT
        right = BOUNDARY_INIT
        up = BOUNDARY_INIT
        down = BOUNDARY_INIT
        first = True

        # 算法Ω：找到能圈住所有标签为1的点的最小矩形
        for i in range(SAMPLE_SIZE):
            # 判断样本点是否在目标矩阵内
            in_target = (TARGET_START <= x[i] <= TARGET_END and
                        TARGET_START <= y[i] <= TARGET_END)

            if in_target:
                total_in_target += 1

                if first:
                    # 第一个正样本点：初始化边界
                    left = right = x[i]
                    down = up = y[i]
                    first = False
                else:
                    # 更新边界以包含当前点
                    if x[i] < left:
                        left = x[i]
                    if x[i] > right:
                        right = x[i]
                    if y[i] < down:
                        down = y[i]
                    if y[i] > up:
                        up = y[i]

        # 计算真实误差-经验误差：目标面积 - 学习到的矩形面积
        learned_area = (right - left) * (up - down)
        error = TARGET_AREA - learned_area

        # 判断是否满足Rademacher复杂度界
        rademacher_bound = (2/SAMPLE_SIZE +
                           math.sqrt(math.log(1/CONFIDENCE_DELTA)/(2*SAMPLE_SIZE)))
        if error < rademacher_bound:
            success_count_1 += 1

        # 判断是否满足VC维界
        vc_bound = math.sqrt((8*3*math.log(2*math.e*SAMPLE_SIZE/3)+8*math.log(4/CONFIDENCE_DELTA))
                    /SAMPLE_SIZE)
        if error < vc_bound:
            success_count_2 += 1

    # ========== 输出结果 ==========
    success_rate_1 = success_count_1 / TEST_COUNT
    success_rate_2 = success_count_2 / TEST_COUNT

    return success_rate_1, success_rate_2

  • 样本复杂度：优化估计仅需32个样本即可达到90%准确率，远小于保守估计的83个样本
  • VC维分析：轴平行矩阵的VC维为3，为泛化界提供了理论基础
  • Rademacher复杂度：复杂度为1/m，与理论分析完全一致
  • 泛化误差界：VC维界相对保守但保证性强，Rademacher界更精确但保证较弱
  • 实验验证：所有理论预测都与实验结果高度吻合，验证了分析的准确性
