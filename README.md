# 绿意不息 | 人工智能与心理学的探索

## 项目简介

这是浙江大学人工智能专业学生绿意不息的个人网站，专注于展示人工智能领域的研究项目和技术探索，同时关注心理学理论对AI发展的启发。

网站采用论文风格设计，简洁优雅，主要展示以下内容：

- **7个深度学习与AI项目**：涵盖大语言模型、强化学习、深度学习框架实现等
- **研究愿景**：探索模型架构优化、训练效率提升和算法创新
- **跨学科视角**：关注心理学对AI发展的启发意义

## 网站特色

### 🎨 设计风格
- **论文风格**：采用简洁、专业的学术风格设计
- **配色方案**：沉稳的深色系配色，体现学术严谨性
- **响应式设计**：完美适配桌面端和移动端设备

### 🔗 文档链接
每个项目都提供了完整的详细文档链接，点击"详细文档"按钮即可查看：
- **TinySeek**：完整的MoE实现细节、训练方法和实验结果
- **EvidenceFlow-UT**：逐层监督损失的理论基础和消融实验
- **SnakeAI**：强化学习算法的超参数设置和训练曲线
- **TinyTorch**：框架架构设计、API使用指南和示例
- **AlphaGomoku**：五子棋AI的技术演进和算法细节
- **Tetris**：游戏开发技术和实现细节
- **Big Integer Arithmetic**：四代技术演进和算法优化

### 📚 核心内容

#### 关于我
- 浙江大学 人工智能专业 绿意不息
- 研究方向：深度学习、强化学习、神经网络架构
- 核心理念：将AI技术与对人类认知的理解相结合，探索更智能的系统

#### 项目展示

1. **TinySeek** - 基于MoE的门控语言模型
   - 混合专家模型架构
   - 样本级门控机制
   - 参数高效微调（LoRA、Prefix Tuning）
   - 包含66张实验图片和12种实验类型

2. **EvidenceFlow-UT** - 逐层监督训练方法
   - Universal Transformer架构优化
   - 逐层监督损失设计
   - 训练策略消融实验
   - 包含21张实验图片和3种实验类型

3. **SnakeAI** - 强化学习智能体
   - Double DQN、Rainbow DQN
   - PPO（近端策略优化）
   - GRPO（群组相对策略优化）
   - 包含7张实验图片和7种实验类型

4. **TinyTorch** - 纯C语言深度学习框架
   - 张量运算库
   - 自动微分系统
   - 神经网络层实现
   - 包含2张实验图片和2个示例

5. **AlphaGomoku** - 五子棋AI
   - 蒙特卡洛树搜索
   - 深度神经网络
   - 自我博弈训练
   - 完整的技术演进历程

6. **Tetris** - 俄罗斯方块游戏
   - C语言游戏开发
   - 图形渲染与事件处理
   - 算法优化实践
   - 包含游戏界面展示

7. **Big Integer Arithmetic** - 大整数运算库
   - 任意精度运算
   - 算法设计与优化
   - 数据结构实现
   - 四代技术演进记录

#### 研究愿景

- **深入探索模型架构优化**：专注于神经网络架构的设计与优化
- **关注心理学的启发**：探索注意力机制、强化学习、证据累积等概念对AI的启发

## 使用方法

### 本地预览

1. 克隆或下载项目到本地
2. 直接在浏览器中打开 `index.html`
3. 或使用本地服务器（推荐）：

```bash
# 使用Python
python -m http.server 8000

# 使用Node.js (http-server)
npx http-server

# 使用PHP
php -S localhost:8000
```

### 部署到GitHub Pages

1. 将项目推送到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择主分支作为发布源
4. 访问 `https://lybx-leyw.github.io/lybx.me`

### 部署到其他平台

网站是纯静态HTML/CSS/JavaScript，可以部署到任何静态网站托管服务：
- Vercel
- Netlify
- Cloudflare Pages
- 阿里云OSS
- 腾讯云COS
